# Правила разработки

Любое изменение должно производиться в соответствии с задачей,
при этом номер задачи должен быть отражен в наименовании ветки.

Любые изменения в ветках `master` / `rc` / `production` должны производиться через механизм Merge Requests,
слияние которых возможно только с согласования ответственных за данный проект:

- `@kosteltsev-mm`
